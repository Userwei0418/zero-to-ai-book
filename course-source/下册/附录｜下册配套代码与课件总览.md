## 环境准备（商汤 Token Plan / 兼容接口）

核心主线（第 03–12 章的本地检索、MCP、Skill、L0–L3 记忆、并发锁与回归评测）**仅依赖 Python 3.9+ 标准库**；需要调用云端大模型或向量/重排能力时，配置以下环境变量：

```bash
export LLM_BASE_URL="https://token.sensetime.com/api/v1"
export LLM_API_KEY="你的密钥"
export LLM_MODEL="sensenova-6.8-flash"

# 可选：Token Plan 向量与重排模型（未配置时自动降级为纯本地 Bigram 混合检索）
export EMBED_MODEL="你的Embedding模型名"
export RERANK_MODEL="你的Rerank模型名"

# 可选：阿里云百炼/通义听悟语音转写密钥（未配置时优先读 .srt 字幕或本地 whisper）
export DASHSCOPE_API_KEY="你的百炼密钥"
```

## 快速自检命令

不用配置任何外部密钥，即可先用离线模式跑通解析、检索、MCP、Skill、记忆、并发锁、回归评测与 CLI：

```bash
# 1. 解析《上册》语料（产出 746 块）
python3 课件/ch03/ingest.py

# 2. 混合检索（本地 Bigram 兜底通道）
python3 课件/ch04/search.py "第 02 章里感知机为什么卡在楼梯灯？"

# 3. MCP 标准协议联调
python3 课件/ch07/mcp_client_demo.py

# 4. 三层 Skill 与确定性统计
python3 课件/ch08/skills.py

# 5. L0–L3 分层记忆与并发锁
python3 课件/ch09/memory.py
python3 课件/ch10/worker.py

# 6. 回归评测（Hit@3 与 MRR）
python3 课件/ch11/eval.py

# 7. 安装毕业项目 mykb CLI
pip install -e 课件/ch12/mykb_pkg
mykb stats
```
