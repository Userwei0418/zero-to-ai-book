# 上册｜理论册：站回当年的问题前

配套课件在这里：[[零基础学AI/attachments/mygpt-companion-20261117-r4-8c90a8fb.zip|下载上册配套代码与实验材料（r4）]]。解压后先读 README，按对应章节说明使用。

上册按问题走：当年卡在哪儿，后来的人怎么翻过去。从规则写不完，到亲手拆开一颗迷你大模型 MiniMind，再到让一句话真的改变一点东西、它自己接着往下做、明天还接得上、交得出去。

全书围绕同一个主线项目——**资料助手**（从 `router.py` v0.1 演进到带验收卡的 v2.0）展开，全部 API 示例统一使用商汤 Token Plan，并通过环境变量读取密钥。

## 配套代码：2026-11-17 r4

这是**可运行的教学代码包，不是已经会办事的资料助手**。Mac Python 3.9.6 新隔离环境实测：默认入口36项正常运行、2项明确的任务质量失败、0崩溃；配套测试19项通过、1项 torch 测试跳过，审批17项通过。592参数模型真实训练、保存并另进程重载；真实小模型仍会答错、输出空任务卡、不选工具，后半章成功机制测试使用明确标注的 mock。

r4 的 README 默认步骤已改为标准库路线，不需要安装 torch；Mac 可直接照第00章「配套包更新」运行。ch9/ch09 虽是有效快照目录，但未登记独立自动脚本，选择它们会明确退出2，不再空跑成功。没有 MiniMind 64M 或 GPU 实测，Mac torch 也未测。包内原文快照不覆盖本地新修订；r3旧包仍保留。
