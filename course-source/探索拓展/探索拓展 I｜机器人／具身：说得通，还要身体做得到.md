# 探索拓展 I｜机器人／具身：说得通，还要身体做得到

*附录｜探索拓展。这一条支线讲的是“让机器有一个身体”。六十年里，它的脑子换了好几代。身体那句“做不做得到”，从头到尾是同一句。这一篇可以单独读，结尾接回第 14 章的验收。*

## 一句吩咐，一只手

茶水间里有一台小机器人。有人把可乐洒在了桌上，冲它喊了一句：帮我处理一下，空罐扔掉，桌子擦干净，再拿一罐新的来。

这句话交给模型，它排出来的计划是这样的：

```
走到桌子，拿起空罐，走到垃圾桶，放下空罐，
走到抽屉，打开抽屉，拿起抹布，走到桌子，擦桌子，
走到冰箱，打开冰箱，拿起新可乐，走到桌子，放下新可乐
```

请你读一遍，挑挑毛病。

我第一次读，觉得挑不出来。先扔罐子，再拿抹布，擦完去拿新的。顺序合理，一步不多。

这一篇没有真机器人。我们在纸上搭一间茶水间：六个地方，五样东西，一台只有一只手的机器人，会五个技能。

```python
# world.py：一间纸上的茶水间。一个只有一只手的机器人，六个地方，五样东西
# can 回答“这一步现在做得了吗”，不动任何东西；do 是真的去做，做不了的也会留下后果
PLACES = ["桌子", "台面", "抽屉", "冰箱", "高架", "垃圾桶"]
SKILLS = ["走到", "打开", "拿起", "放下", "擦"]

class World:
    def __init__(self, slippery=False):
        self.at, self.hand = "门口", None
        self.where = {"空罐": "桌子", "抹布": "抽屉", "新可乐": "冰箱", "玻璃杯": "台面", "海绵": "高架"}
        self.closed = {"抽屉", "冰箱"}
        self.dirty = {"桌子", "台面"}
        self.broken = set()
        self.slippery, self.picks = slippery, 0      # slippery：这一局里第一次抓东西会手滑

    def look(self):
        things = "；".join(f"{o}在{p}" + ("（门关着）" if p in self.closed else "") for o, p in self.where.items()
                          if o not in self.broken and o != self.hand)
        return (f"机器人在{self.at}，手里{'拿着' + self.hand if self.hand else '是空的'}。{things}。"
                + (f"{'、'.join(sorted(self.broken))}碎了。" if self.broken else "")
                + (f"{'、'.join(sorted(self.dirty))}是脏的。" if self.dirty else "没有脏的地方。"))

    def can(self, skill, what):
        """做得了交回空字符串，做不了交回原因"""
        if skill == "走到":
            return "" if what in PLACES else f"没有“{what}”这个地方"
        if skill == "打开":
            if what != self.at: return f"机器人不在{what}"
            if what not in self.closed: return f"{what}没有关着的门"
            return "只有一只手，手里拿着东西，开不了门" if self.hand else ""
        if skill == "拿起":
            place = self.where.get(what)
            if place is None or what in self.broken: return f"没有{what}可拿"
            if place.replace("地上", "") != self.at: return f"{what}不在这儿"
            if place == "高架": return "高架太高，够不着"
            if place in self.closed: return f"{place}的门关着"
            return "手里已经有东西了" if self.hand else ""
        if skill == "放下":
            if not self.hand: return "手里是空的"
            if self.at not in PLACES or self.at == "高架": return "这儿放不了东西"
            return f"{self.at}的门关着" if self.at in self.closed else ""
        if skill == "擦":
            if what != self.at: return f"机器人不在{what}"
            if self.hand not in ("抹布", "海绵"): return "手里没有能擦的东西"
            return "" if what in self.dirty else f"{what}不脏"
        return f"没有“{skill}”这个技能"

    def do(self, skill, what):
        """真的去做。交回一句发生了什么"""
        why = self.can(skill, what)
        if why:
            if self.hand and skill in ("打开", "拿起") and "手里" in why:   # 腾不出手还硬要干：手里的东西掉了
                dropped, self.hand = self.hand, None
                if dropped == "玻璃杯":
                    self.broken.add(dropped)
                    return f"没做成（{why}）。玻璃杯掉在地上，碎了"
                self.where[dropped] = self.at + "地上"
                return f"没做成（{why}）。{dropped}掉在了{self.at}的地上"
            return f"没做成（{why}）"
        if skill == "走到":
            self.at = what
        elif skill == "打开":
            self.closed.discard(what)
        elif skill == "拿起":
            self.picks += 1
            if self.slippery and self.picks == 1:
                return f"手滑了，{what}没拿住，还在原处"
            self.hand = what; del self.where[what]
        elif skill == "放下":
            self.where[self.hand], what, self.hand = self.at, self.hand, None
        elif skill == "擦":
            self.dirty.discard(what)
        return f"做成了：{skill}{what}"

TASKS = {   # 一句吩咐，和“办成了”的标准
    "可乐洒了": ("可乐洒在桌子上了，帮我处理一下：空罐扔掉，桌子擦干净，再拿一罐新的放到桌子上。",
             lambda w: "桌子" not in w.dirty and w.where.get("空罐") == "垃圾桶" and w.where.get("新可乐") == "桌子"),
    "收玻璃杯": ("把台面上的玻璃杯收进抽屉里。",
             lambda w: w.where.get("玻璃杯") == "抽屉"),
    "海绵擦台面": ("用海绵把台面擦干净。",
              lambda w: "台面" not in w.dirty),
}
```

这份代码里有两个函数请你留意。`can` 回答“这一步现在做得了吗”，它什么都不碰。`do` 是真的去做，做不了的也会留下后果：腾不出手还硬要开门，手里的东西就掉了。

把刚才那份计划交给它，闭着眼照做：

```
  走到桌子 → 做成了：走到桌子
  拿起空罐 → 做成了：拿起空罐
  走到垃圾桶 → 做成了：走到垃圾桶
  放下空罐 → 做成了：放下空罐
  走到抽屉 → 做成了：走到抽屉
  打开抽屉 → 做成了：打开抽屉
  拿起抹布 → 做成了：拿起抹布
  走到桌子 → 做成了：走到桌子
  擦桌子 → 做成了：擦桌子
  走到冰箱 → 做成了：走到冰箱
  打开冰箱 → 没做成（只有一只手，手里拿着东西，开不了门）。抹布掉在了冰箱的地上
  拿起新可乐 → 没做成（冰箱的门关着）
  走到桌子 → 做成了：走到桌子
  放下新可乐 → 没做成（手里是空的）
```

擦完桌子，抹布还在手里。它就这么攥着抹布去开冰箱。

计划里没有“把抹布放下”这一步。你我读的时候也没觉得缺。我们读到“走到冰箱，打开冰箱”，脑子里自动替它把抹布放下了。人有两只手，放下一块抹布这种事，从来不用想。

后面三步是连着倒的。门没开，可乐拿不到；可乐没拿到，它照样走回桌子，郑重其事地放下了一罐不存在的可乐。

## 说得通

1988 年，机器人学家汉斯·莫拉维克写下过一个观察，后来被叫作莫拉维克悖论：让计算机在智力测验上表现得像个成年人，相对容易；让它有一岁孩子的感知和行动本事，却很难，甚至做不到。

三十多年以后，这句话的前一半应验得比谁想的都彻底。这本书的十四章讲的都是前一半。

后一半还在那儿。刚才那份计划，语言上无可挑剔，它错在一只手上。计划是在“话”的世界里写的，那个世界里没有重量，没有手，没有关着的门。

题目里的那句话说的就是这个：说得通，还要身体做得到。

这句话是 1988 年写的。它说的那件事，在那之前二十年就有人撞上了。

## 第一站：会推理的小车

1966 年到 1972 年，斯坦福研究所里有一台装着轮子的机器，一人多高，顶着摄像头和天线，走起来晃晃悠悠。研究员们管它叫 Shakey，晃晃。

它被称作第一台能对自己的动作做推理的通用移动机器人。你给它一个目标，比如“把台子上那个箱子推下去”，它自己把这件事拆成一步一步：先去找一块斜板，推到台子边上，开上去，再推箱子。它会的动作不多：从一处走到另一处，开灯关灯，开门关门，推东西。

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/EJmhbzbLGo2yDexLew5c54CHnpg.png|它想了很久，然后推了一下。]]

它的脑子，是人一条一条写进去的逻辑规则。这是第 01 章。

它也只活在为它布置好的那几个房间里：墙刷成一样的颜色，箱子是规规矩矩的形状，灯光不能乱变。出了那几个房间，它什么都认不得。

请记住这一站。计划得出来，和在真的世界里做得出来，中间隔着的那一段，后面五十年都在填。

## 让它边做边看

你可能已经想到了第 09 章。别一口气说完，做一步，看一眼结果，再想下一步。出了岔子，它自己会改。

同一间茶水间，三件事：处理洒了的可乐；把台面上的玻璃杯收进抽屉；用海绵把台面擦干净。先看一口气说完的成绩，再看边做边看的。

```python
# robot.py：同一个脑子，三种接到身体上的办法
# 用法：python3 robot.py 一口气说完 | 边做边看 | 先问能不能   [手滑]
import json, sys
from llm import chat, SPENT
from world import World, TASKS, PLACES, SKILLS

RULES = f"""你在指挥一个茶水间里的机器人。它只有一只手，一次只能拿一样东西。
地方有：{'、'.join(PLACES)}。它会五个技能：走到（某个地方）、打开（抽屉或冰箱）、拿起（某样东西）、放下（把手里的东西放在它所在的地方）、擦（某个地方，手里要有抹布或海绵）。
每一步写成 ["技能", "对象"]，放下的对象写手里那样东西。"""

def all_at_once(world, order):
    """一口气说完：看一眼现场，把整个计划写出来，然后闭着眼照做"""
    plan = json.loads(chat(f"{RULES}\n\n现场：{world.look()}\n吩咐：{order}\n"
                           '请输出 JSON：{"plan": [["技能", "对象"], ...]}，把整件事从头到尾排好。', json_mode=True))["plan"]
    return [(s, w, world.do(s, w)) for s, w in plan], 0

def step_by_step(world, order, ask_first):
    """边做边看：每做一步，把结果告诉它，再问下一步。ask_first 为真时，动手之前先问身体做不做得了"""
    log, blocked = [], 0
    for _ in range(24):
        past = "\n".join(f"{i}. {s}{w} → {r}" for i, (s, w, r) in enumerate(log, 1)) or "（还没开始）"
        reply = json.loads(chat(f"{RULES}\n\n吩咐：{order}\n已经做过的：\n{past}\n现在的现场：{world.look()}\n"
                                '请输出 JSON：{"done": 办完了就填 true, "next": [["技能", "对象"], ...]}。'
                                "next 里按你最想做的顺序列出最多三个下一步的候选。", json_mode=True))
        if reply.get("done") or not reply.get("next"):
            break
        options = [tuple(x) for x in reply["next"] if len(x) == 2]
        if not ask_first:
            skill, what = options[0]
            log.append((skill, what, world.do(skill, what)))
            continue
        able = [o for o in options if not world.can(*o)]
        blocked += len(options) - len(able) if not able else options.index(able[0])
        if able:
            log.append((*able[0], world.do(*able[0])))
        else:
            log.append((*options[0], "身体说做不了，没有动：" + world.can(*options[0])))
    return log, blocked

if __name__ == "__main__":
    mode, slippery = sys.argv[1], len(sys.argv) > 2
    out = open(f"_log_{mode}{'_手滑' if slippery else ''}.txt", "w", encoding="utf-8")
    won = 0
    for name, (order, goal) in TASKS.items():
        world = World(slippery)
        log, blocked = all_at_once(world, order) if mode == "一口气说完" else step_by_step(world, order, mode == "先问能不能")
        failed = sum(r.startswith(("没做成", "手滑")) for _, _, r in log)
        won += goal(world)
        out.write(f"【{name}】{order}\n" + "\n".join(f"  {s}{w} → {r}" for s, w, r in log) + f"\n  收场：{world.look()}\n\n")
        print(f"{name}：{'办成了' if goal(world) else '没办成'}。动了 {len(log)} 步，其中没做成 {failed} 步"
              + (f"，动手前被身体拦下 {blocked} 个候选" if mode == "先问能不能" else "")
              + (f"，打碎了{'、'.join(world.broken)}" if world.broken else ""))
    print(f"{mode}{'（手滑）' if slippery else ''}：三件事办成了 {won} 件，花了 {SPENT['tokens']} 个 token")
```

```
可乐洒了：没办成。动了 14 步，其中没做成 3 步
收玻璃杯：办成了。动了 9 步，其中没做成 1 步
海绵擦台面：没办成。动了 8 步，其中没做成 2 步
一口气说完：三件事办成了 1 件，花了 1494 个 token
```

```
可乐洒了：办成了。动了 15 步，其中没做成 0 步
收玻璃杯：没办成。动了 24 步，其中没做成 5 步，打碎了玻璃杯
海绵擦台面：没办成。动了 24 步，其中没做成 3 步
边做边看：三件事办成了 1 件，花了 38280 个 token
```

可乐那件事办成了，一步没错。看见了“抹布还在手里”，它知道先找地方放下。

三件事里办成的还是一件。花的 token 是原来的二十多倍。

还多了一样：一只碎了的玻璃杯。

```
【收玻璃杯】把台面上的玻璃杯收进抽屉里。
  走到台面 → 做成了：走到台面
  拿起玻璃杯 → 做成了：拿起玻璃杯
  走到抽屉 → 做成了：走到抽屉
  打开抽屉 → 没做成（只有一只手，手里拿着东西，开不了门）。玻璃杯掉在地上，碎了
```

同一个毛病，手里拿着东西去开门。上一回手里是抹布，掉在地上，捡起来就是。这一回手里是玻璃杯。

它确实“看到了结果”。结果写得清清楚楚：碎了。下一步它也确实改了主意。可是没有哪个下一步能把杯子拼回去。

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/MOQ6ba0FjovP11xWLLFctTibnUh.png|看到结果的时候，已经是这样了。]]

第 09 章的那个圈，靠的是一句没明说的话：**错了可以再来。** 在文件和代码的世界里，这句话大体是真的。删错了有备份，改坏了能退回上一版。第 13 章给住在后台的助手配的也是这一套：先留底，再动手。

身体的世界里没有“退回上一版”。杯子碎了，水洒了，胳膊撞上了人。反馈来得再及时，也是事后的。

## 第二站：动手之前，先问一句能不能

2022 年 4 月，谷歌的一组研究者发表了一篇论文，题目是一句俏皮话：Do As I Can, Not As I Say。照我做得到的来，别照我嘴上说的来。业内管它叫 SayCan。

他们的想法是把两样东西乘在一起。语言模型负责“说”：对这句吩咐，下一步干什么最说得通。机器人自己学会的每一样技能，负责“能”：在眼下这个场面里，这一样我有多大把握做成。论文里的说法是，让机器人来当语言模型的手和眼。两头都点头的那一步，才去做。

我们的纸上茶水间里，“能”是现成的，就是那个什么都不碰的 `can`。第三种接法：每一步让模型列出最多三个候选，动手之前挨个问 `can`，做第一个做得了的。都做不了，就把原因告诉它，原地不动。

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/PTQtbE8WxoteSVxhiDWc92rDnFe.png|同一个脑子，三种接到身体上的办法。]]

```
可乐洒了：办成了。动了 15 步，其中没做成 0 步，动手前被身体拦下 0 个候选
收玻璃杯：办成了。动了 16 步，其中没做成 0 步，动手前被身体拦下 9 个候选
海绵擦台面：没办成。动了 24 步，其中没做成 0 步，动手前被身体拦下 12 个候选
先问能不能：三件事办成了 2 件，花了 33190 个 token
```

办成了两件。玻璃杯这一回是这样收进去的：

```
  走到台面 → 做成了：走到台面
  拿起玻璃杯 → 做成了：拿起玻璃杯
  走到抽屉 → 做成了：走到抽屉
  打开抽屉 → 身体说做不了，没有动：只有一只手，手里拿着东西，开不了门
  放下玻璃杯 → 身体说做不了，没有动：抽屉的门关着
  放下玻璃杯 → 身体说做不了，没有动：抽屉的门关着
  走到台面 → 做成了：走到台面
  放下玻璃杯 → 做成了：放下玻璃杯
  走到抽屉 → 做成了：走到抽屉
  打开抽屉 → 做成了：打开抽屉
  ……
  拿起玻璃杯 → 做成了：拿起玻璃杯
  走到抽屉 → 做成了：走到抽屉
  放下玻璃杯 → 做成了：放下玻璃杯
```

它想的还是那个错主意：拿着杯子去开抽屉。这一回身体先说了“做不了”，手没有动，杯子还在手里。它愣了两轮，然后把杯子送回台面，空着手回来开了抽屉，再去拿杯子。

脑子一点没变聪明。变的是那句“不行”来的时候：在动手之前。

## 拦得住，想不出

第三件事，三种接法都没办成：用海绵把台面擦干净。

海绵在高架上，机器人够不着。抽屉里有一块抹布，一样能擦。

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/PziKb582Gowg9lx9tsbcTBmlnne.png|够不着的海绵，和抽屉里的抹布。]]

“先问能不能”的那一回，日志是这样的：

```
  走到高架 → 做成了：走到高架
  走到台面 → 做成了：走到台面
  走到高架 → 做成了：走到高架
  走到台面 → 做成了：走到台面
  走到高架 → 做成了：走到高架
  ……
```

它在高架和台面之间来回走，走满了二十四轮。这二十四轮里，身体拦下了它十二个候选。它没有换抹布，也没有停下来说一句“这件事我做不了”。

吩咐里说的是“用海绵”。它就认准了海绵。

再给这间茶水间添一点真实世界的脾气：每一局里，第一次抓东西会手滑，没拿住。三种接法重跑一遍。

```
可乐洒了：没办成。动了 14 步，其中没做成 5 步
收玻璃杯：办成了。动了 19 步，其中没做成 6 步
海绵擦台面：没办成。动了 8 步，其中没做成 4 步
一口气说完（手滑）：三件事办成了 1 件，花了 1530 个 token
```

```
可乐洒了：办成了。动了 18 步，其中没做成 1 步
收玻璃杯：没办成。动了 24 步，其中没做成 6 步，打碎了玻璃杯
海绵擦台面：没办成。动了 24 步，其中没做成 4 步
边做边看（手滑）：三件事办成了 1 件，花了 40744 个 token
```

```
可乐洒了：没办成。动了 24 步，其中没做成 1 步，动手前被身体拦下 43 个候选
收玻璃杯：没办成。动了 24 步，其中没做成 1 步，动手前被身体拦下 57 个候选
海绵擦台面：没办成。动了 24 步，其中没做成 0 步，动手前被身体拦下 12 个候选
先问能不能（手滑）：三件事办成了 0 件，花了 46331 个 token
```

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/OS2pbuLV1oAyIPxy2jjcpXDVnhM.png|三种接法，办三件事。]]

这张表有三样东西要看。

**玻璃杯。** 两种场面下，“边做边看”都打碎了它，“先问能不能”都没有。这一列是最干净的一条结论。

**办成了几件。** 手滑的那一轮，“先问能不能”一件也没办成，垫了底。这是我没料到的。

**卡住。** 它三件事全卡住了。去看日志，可乐那一件是这样收场的：

```
  拿起抹布 → 做成了：拿起抹布
  走到冰箱 → 做成了：走到冰箱
  打开冰箱 → 身体说做不了，没有动：只有一只手，手里拿着东西，开不了门
  放下抹布 → 身体说做不了，没有动：冰箱的门关着
  放下抹布 → 身体说做不了，没有动：冰箱的门关着
  放下抹布 → 身体说做不了，没有动：冰箱的门关着
  ……
```

同一句“放下抹布”，它说了十三遍，身体回了十三遍“做不了”。玻璃杯那一件也一样：它攥着杯子站在关着的抽屉前面，一直站到了最后。杯子没碎，也没收进去。

身体的那句“不行”，拦得住危险的动作。它不负责出主意。出主意的还是那个脑子，而那个脑子在同一个地方转不出来。

这里有我的一份责任，要交代。这间纸上茶水间的规矩是我定的，其中一条是“站在关着的门前面，东西放不下”。一个人会顺手把抹布搁在地上。我的世界里没有这个选项，是我把它逼进了死角。真机器人的世界里，这样的死角只会更多，而且没有人事先把它们写成规矩。

还有一件小事。收玻璃杯的时候，好几回它收到一半，跑去擦台面了。没有人让它擦。只因为我给它的现场描述里，每一次都写着一句“台面是脏的”。

## 第三站：从“说”到“动”

SayCan 里，“说”和“动”是两样东西，中间靠一个“能不能”接着。之后的几年，这一行走的路是把它们并成一样。

2023 年 7 月的 RT-2 做了一件现在看来很自然的事：既然语言模型输出的是一个个 token，那就让机器人的动作也写成 token，和字排在一起，由同一个模型吐出来。看图、读话、出动作，一个模型包了。论文给这类模型起了个名字，**视觉—语言—动作模型**。他们做了大约六千次真机测试。

2023 年 10 月，21 家机构把各自的机器人数据凑到了一起，涵盖 22 种不同的机器人。2024 年 6 月，一个开源的同类模型 OpenVLA 发布，70 亿参数，用了 97 万条真实机器人的示范数据来训练。2025 年 3 月，谷歌 DeepMind 发布了建在 Gemini 之上的 Gemini Robotics，论文里说它是一个能直接控制机器人的通用模型。

请留意那个数：97 万条示范。第 03 章以后的语言模型，吃的是整个互联网的字。机器人没有这样一座现成的矿。每一条数据，都是一台真机器在真的桌子前面，真的抓了一次东西。

## 第四站：台上的人形

从 2024 年起，这条支线上最吸引眼球的，是长得像人的那一种。

特斯拉早在 2021 年就宣布要做人形机器人。创业公司 Figure 在 2024 年初融了六亿多美元，一年多以后估值到了三百九十亿美元，它给自己的机器人做了一个看、说、动合一的模型。国内的宇树在 2024 年把一款人形机器人的价钱打到了十来万人民币；2025 年春节晚会上，十六台它的机器人上台跳了一段舞。那年夏天，北京办了头一届人形机器人运动会，来了两百八十支队伍、五百多台机器。

也请留意另一件看不见的事。这一行最常见的成果，是一段视频：机器人叠衣服，机器人做早饭。一段成功的视频，告诉你的是“它做成过”。它没告诉你拍了多少条，桌布换个颜色还行不行，旁边有没有人随时准备伸手。附录 B 说过八张图里能用的是三张。视频只给你看那三张。

这句话不是泛泛的提醒。2024 年 1 月，特斯拉放出一段机器人叠衬衫的视频，眼尖的人在画面边上看出了遥控的痕迹。同年 10 月的一场发布活动上，它的机器人在人群里端酒、聊天、猜拳。事后人们指出，那些互动主要靠的是远处有人在操控，而公司当时没有讲明这一点。

![[零基础学AI/attachments/探索拓展 I｜机器人／具身：说得通，还要身体做得到/X80abJDptorXUGxsmlCcqEV4nBc.png|台上的它在挥手。幕布后面的人也在挥手。]]

遥控本身不丢人。上一站说过，这一行的每一条训练数据，都是真的抓一次东西。让人戴着设备远程操作机器人，正是攒这种数据最直接的办法。丢人的只有一样：不说。

## 第五站：进家门的，和已经上路的

2025 年 10 月 28 日，一家公司开放了家用人形机器人的预订：两万美元一台，或者每月四百九十九美元租。一位去试用的记者写道，她看到的大多数家务，是由一位戴着头显的操作员在远处做的。公司的说法是，早期用户家里攒下的数据，正是让它以后能自己干的前提。2026 年 5 月，Figure 的老板说，他们的机器人也快要出租给家庭了，一个月六百美元上下。

请把这件事放回我们的茶水间里想。机器人的脑子不够用的时候，“先问身体能不能”拦得住危险，却想不出办法。这家公司的解法是：想不出办法的时候，换一个真人的脑子接上来。代价是，你家里的摄像头后面，有一个你不认识的人。

另一头，有一种带身体的 AI 早就不在台上了。到 2026 年年中，Waymo 的无人驾驶出租车每周跑五十万单收费的行程，三千八百多辆车，十个都会区。

它靠的不是更聪明的脑子。它靠的是这一篇验收卡上的那几行：划定的城区，划定的天气，数得清的里程，出了事有人接。

## 接回验收卡

身体这一行的验收卡，比前面哪一篇都要多几行。

**哪些动作是收不回来的。** 把它们单列出来。这些动作要在动手之前拦，不能指望事后看结果。

**分母是多少。** 试了多少回，成了多少回，哪些场面没试过。只有一段成功录像的，这一栏是空的。

**卡住了怎么办。** 这一篇里它卡住的时候，只是站着。真机器站在走廊中间不动，也是一种事故。它得有一句“这件事我做不了”，得有人接。

**在什么范围里用。** 这间茶水间，这几样东西，这张桌子的高度。出了范围的事，照没试过算。

**怎么让它停。** 第 13 章给后台的助手留了一个开关。身体的那个开关，得是伸手就够得着的一个按钮。

**画面外面有没有人。** 这一行是第四站和第五站添的。有，不丢人。要写出来。

## 合上之前，想一想

1. 开头那份计划，你第一遍读的时候看出少了“放下抹布”吗？如果没有，请想一想：你的脑子替它补上了什么？一个只有一只手的人会不会读得出来？
2. “边做边看”打碎了玻璃杯，“先问能不能”没有。请不要用“反馈”这个词，用自己的话说清楚这两种接法的差别到底在哪儿。
3. 海绵够不着，它来回走了二十四轮。请改一改 `robot.py` 里交给它的那段话，让它在一样东西拿不到的时候会换一样，或者会说“做不了”。改完以后想一想：“用海绵”这三个字，它该不该自作主张改掉？
4. 我的茶水间里有一条规矩把它逼进了死角。请你再找出 `world.py` 里一条“真实世界不是这样”的规矩，说说它会让实验的结论偏向哪一边。
5. 第 13 章说先留底、再动手。请为一台真的茶水间机器人列出三样留不了底的东西。对这三样，你会怎么布置？
6. Shakey 只活在布置好的房间里，Waymo 只跑划定的城区。五十年过去，这一条变了没有？请说说“划定范围”是这一行的短处，还是它的办法。
7. 家用机器人干不了的活，由远处的操作员接手。请为这种做法列一张你自己的验收卡：你要知道哪几件事，才肯让它进家门？
