# 从零开始学 AI
## 从会回答，到能做事

如果回到 AI 历史上的那些岔路口，只拿着当时的信息，你会怎样选择？

规则为什么总也写不完？给了例子，机器就能学会吗？模型已经很聪明，为什么还做不好你手头的工作？

《从零开始学 AI》邀请你带着这些问题，走进七十年间一个个突破发生之前的现场。先猜一猜，自己选一次，再动手做个小实验，看见问题怎样被解决，又留下了什么新的难题。每一个新概念，都从你亲自遇到的困惑里生长出来。

上册围绕同一个“资料助手”展开。从六行规则开始，你会逐步理解机器学习、强化学习、语言模型与推理，再为助手接上资料、工具、技能和记忆。它会增加本事，也会犯错。你将追着一次次真实的结果，学会判断问题出在哪里、该补上哪一块，以及怎样确认事情真的做成了。

下册把上册本身变成你的第一座知识库。从一个文件夹出发，用 Python 搭建解析、检索、带出处的问答与 MCP 服务，继续动手练习自主循环、分层记忆、协作和自动评测。读过的知识，成为你可以拆开、运行、修改的作品。

十篇行业拓展，再带你走进编程、视频、游戏、设计、办公、声音、科学、教育、机器人，以及医疗与法律，看看同样的思路进入不同工作现场，会遇到哪些新的问题。

学完之后，你面对一个新模型、新工具或新框架，可以更有把握地问出自己的问题，也能着手把它接进真实的工作。

适合 AI 零基础、会一点 Python 的学习者。能看懂循环和函数、运行一个脚本，就可以开始。

**回到历史的岔路口，搭出自己的 AI 助手。**
