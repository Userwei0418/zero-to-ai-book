# 写在最后

书写完了，想跟你说几句心里话。

## 学完这些，你手里有了什么

先说一句我最想说的：读到这儿，你应该已经不怕这些东西了。

刚开始的时候，Agent、记忆、工具调用、skill，这些词听着都很玄，好像背后站着一群我们够不着的人。

现在你知道了。

模型做的事，是学着接下一句。提示词是一张任务卡。工具调用是它从门缝里递出来的一张纸条，外面有个程序替它去办。记忆是写在它外面的一个本子，下回开工再读回来。skill 是一张做法卡片。多 Agent 是多请了几个帮手，一个写，一个查。

至于 Agent，说到底就是一个循环。想一步，做一步，看一眼结果，再想下一步。你在第 09 章见过它，到了下册，你会亲手敲出它来，六十来行。

下册里你要一点一点搭起来的那个知识库，会查你的笔记，会整理卡片，记得你说过的事，还能接进 WorkBuddy、Claude Code 这些你天天在用的工具里。拆开看，全是普通的 Python，只用了自带的库。

这些东西没有一样是魔法。它们全是代码，而且大多是很朴素的代码。

所以这本书我最想让你带走的一句话是：**代码和算法，才是整件事的底座。** 模型很聪明，可是让它真的做成一件事的，是围着它的那一圈程序；而掀开模型自己的盖子，里面也是代码和算法——第 02 章的反向传播是在计算图上倒着做动态规划，第 03 章的强化学习是在时间轴上做动态规划，第 04 章的切词与注意力是数据结构和矩阵乘法，第 09 章的 Agent 是一个状态机循环，第 11 章的记忆检索和第 12 章的多助手协作，背后全是操作系统和工程里的老问题。你看懂了底座，往后再出什么新名词，你都能问一句“它无非是在哪一步上又加了点什么”，然后八九不离十地猜出来。

## 我为什么用这种语气讲

你可能觉得奇怪，这本书为什么总是把你推回当年，让你对着一个还没人解开的问题先站一会儿，就是不肯痛痛快快把答案给你。

因为答案现在太不值钱了。

你想知道什么是注意力，什么是 RAG，随便找一个 AI 问，它都讲得出来，讲得比我好。一套只讲概念的教程，在今天我觉得已经没有意义了。

真正值钱的是另一样：这个问题真的摆到你自己面前的时候，你会怎么办。

我自己是这么过来的。把自己放回当时那个位置去想，想不出来再去看前面的人怎么做的。看多了我发现一件挺有意思的事：那些走在最前面的人，用的办法也不是天上掉下来的。有的是从操作系统里借的，有的是从传统的软件开发里借的，有的你往上追，能一路追到咱们古代的三省六部，一个拟，一个审，一个办。

都是历史上解过的题，换了个地方又解了一遍。

以史为鉴，说的就是这个。你肚子里装着这些，等到下一个问题来的时候，说不定就能灵光一现。那个冲在前面的人，为什么不能是你呢。

## 生不逢时还是正当其时？

说点我自己的事。

最近软件行业很冷，大家都说是寒冬。

我学计算机的时候有个毛病，学完前一章，喜欢自己先琢磨下一章会讲什么，常常真能悟出一点来。每到这种时候我就特别感慨，觉得自己生不逢时。要是早生个几十年，这些东西还没人想出来，说不定我也能成个什么人物。

后来我想明白了。这个机会其实又来了一回，就落在我们这一代人头上。

今天 Agent 面前那些没解决的问题，跟几十年前摆在前辈面前的那些，是一回事。没有标准答案，谁也不比谁多知道多少，大家都在摸。

那还感慨什么呢。老老实实学，使劲追，尽量往前头站。说不定真能为这个时代出一份力。

## 从深度优先，到广度优先

还有一个想法，在我心里放了很久。学过算法的人都认得两个词，深度优先和广度优先。我觉得它们恰好能说清楚，这个时代对我们普通人意味着什么。

先说从前。

没有 AI 的时候，一个人要活出价值，走的是深度优先。就像打一口井：选一个地方，一直往下挖。人的精力就那么多，你找一个自己擅长的行当，扎进去，耕上几十年。挖得越深，出水越多，价值也就越高。我们身边那些被叫作“大牛”的人，几乎都是这么挖出来的。

再说现在。

有了 AI，这口井突然变浅了。讲某一个行当里的知识，我猜十个人里有九个，穷尽一辈子也学不过它。人类几千年攒下来的经验，它一口气读完了。我们一辈子可能都读不透。你拼了二十年挖到的第七层，它也许一伸手就到了。

那我们还挖什么？

我转念一想，这个时代留给我们的，也许是一场广度优先。

![[零基础学AI/attachments/写在最后/AhfXbRtoXoY1CoxaE5NcfiDEnTd.png|从前是一口井打到底。现在是一棵树，每根枝上都有人扶你一把。]]

画出来是这个样子：

![[零基础学AI/attachments/写在最后/Y2FtbbTjhohc9Axjw21c3jROn3d.png|深度优先，和广度优先。]]

左边是从前：一个领域，七八层。右边是现在：你自己在每个领域里走两三层，剩下的三四层，AI 扶着你走。走五个领域，每个都到五六层。

可是请看那些虚线框。AI 扶得动你，前提是你自己已经站在那块地上了。它扶不了你去一个你从来没去过的地方。

为什么？因为 AI 是人的能力的一面镜子，也是一个放大镜。你越懂一件事，越说得清楚自己要什么，它就把你放大得越厉害。两个人，干同一件事，用同一个模型，出来的东西真不一样。

![[零基础学AI/attachments/写在最后/SnJhb5SNJooMdEx5202cv68xnRb.png|同一面放大镜。照出来的大小，看你手里拿的是什么。]]

左边那位手里只有一张草图，放大出来是一团模糊。右边那位手里是一张画满了细节的地图，放大出来的东西又大又清楚。放大镜是一样的。

也许以后 AI 更强了，这个差距会被抹平。可我总觉得抹不太平。一样东西你连见都没见过，你压根不知道该怎么开口。你开不了口，它就帮不了你。

所以我觉得，往后拼的是见得多。

时间还是那么多。可是有它扶着，我们能看到的行当比以前多太多了。以前在一个领域里要走到七八层才算有价值，现在你自己走到两三层，它扶你一把，很快就到五六层。你在四五个领域里都有五六层，我觉得这样的一辈子，比原来更有分量。

还有一件更妙的事：这些领域是相通的。

你在一个领域里卡住了，面前是一堵光溜溜的墙，怎么也爬不上去。隔壁那个领域里，可能早就有一把现成的梯子。这本书里你见过好多回：几个 Agent 一个拟、一个审、一个办，像极了三省六部；给它划一块沙箱、只给最小的权限，是操作系统几十年前就想明白的事；先写好测试再让它改代码，是传统软件开发里的老规矩。

![[零基础学AI/attachments/写在最后/LPpabQH73oMYmvxuiXcc48cxnoK.png|隔壁园子里，有人把梯子递了过来。]]

那张示意图上，五口浅井之间的那几道横杠，就是这些梯子。灵光一现，常常就发生在横杠上。

AI 始终只是一个工具。它能带着我们变强，也能把我们已有的本事放大。可它放大的，得先是你的。

## 一个我没见过的方案

讲一件我最近工作里的真事。

我们的负载均衡是在另一家服务商那儿买的。它那边的服务器跟 A 服务商这边没打通，负载均衡加不上。

我去问一位技术老师，还有没有别的办法。他给我提了一个 VIP（虚拟 IP）的方案。我回去研究了一下，确实巧。

研究完我愣了一会儿。

我发现我并不需要弄清楚这个方案每一行代码怎么写。我要知道的是：有这么一种办法，能解决这么一类问题。

这就是见过和没见过的区别。我要是没见过，我这辈子也说不出那一句提示词，让 AI 替我把它做出来。

所以广度真的要紧，阅历真的要紧。我们正在从动手干活的人，变成拿主意、搭架子的人。程序出了问题，大概出在哪儿。碰到一个技术难题，有哪几条路可以走。这才是这个时代更该攒下来的东西。

## 那我们还学什么，路上又该怎么走

常有人问：AI 都这么强了，我们学代码、学算法还有意义吗？

上面说的就是意义。软件行业是在过冬，可是你不懂软件、不懂算法，往后反而更难走远。写程序会越来越像认字，人人都得会一点；而真正拉开差距的，是你知不知道程序底下怎么转、问题出在哪一层。往后一定是“程序加 AI”，这一点不会变。

还有一件事，是写完这十四章以后我特别想补给你的：**这一路上的每一站，都值得停下脚步，好好研究一阵。**

很多人学 AI 恨不得一步跨到最新的模型、最新的 Agent 框架，觉得 1958 年的感知机、1966 年的 ELIZA、1986 年的四页论文、1992 年的自我对弈都是老古董，扫一眼名词就过去了。可你如果真的停下来，亲手把 `perceptron.py`、`value.py`、`maze.py` 敲一遍、调一遍，会发现一件很神奇的事：**后面所有大模型和 Agent 系统里让人头疼的坑——规则打架、死记硬背、刷分作弊、长链路算不清账——其实在当年那一小步里全演过一遍。** 走得太快，往往只记住了一堆新词；反倒是肯在关键的站台停下来把原委看透的人，走到下一站时脚下最稳。

## 都是一个脑子

四年前我刚才大一，学 C 语言，听的是翁凯老师的课。听着听着心里冒出一个念头，一直记到今天：这些程序再厉害，也是人写出来的。大家都只有一个脑子，他们能做出来，我们凭什么不能？

这一回我算是亲身把 Agent 这段历史走了一遍。回头一看，那些后来被证明行得通的路子，跟我自己当时瞎琢磨的，居然大差不差。那种感觉很梦幻，我到现在想起来还有点激动。

从规则到训练，从问答到工具，到 skill，到 Agent，到记忆。哪有什么一步登天，每一步都只是在解决当时眼前真真切切的那个问题。

这样的问题，前面还有一大堆没人解。

## 趁现在

我觉得我们正赶上一次像蒸汽时代走向电气时代那样的跨越。所有的行当，早晚都要拿新办法重做一遍。现在也许还不到时候，阻力很大，可方向一定是这个方向。

机会往往一晃就过去了。我们能做的准备只有一样：一直去碰它，去用它，用完了多想一想。

![[零基础学AI/attachments/写在最后/GhcXb3wgQopsSpxV99ScOA2Jnoc.png|大家差不多还站在同一条线上。]]

趁现在，大家都还在差不多的起跑线上。

接下来书末还有一份**附录（探索拓展 A–J）**，把主线学到的这套东西放进了十个不同的行当里：软件开发、视频短剧、游戏、设计、日常办公、声音、科研、教育、具身机器人，还有医疗与法律。前面我们聊到“先有广度，再让 AI 放大”，你可以先去那十条支线里逛一圈，**挑一两个你最感兴趣、或者刚好贴近你手头工作的方向，真正扎进去研究一阵**；看对眼了，再翻开**下册**，从零动手搭一个属于你自己的知识库助手。

去想，去试，去追吧。

愿你在这个时代，做出一点属于自己的东西。
