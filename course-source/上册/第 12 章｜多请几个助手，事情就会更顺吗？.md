## 一个写，一个查

上一章结尾，资料助手一个人干着五样活：查规定，写清单，自己说“已存好”，自己整理交接包，夜里再自己核自己的笔记。核的那一遍，9 条里挑出 6 处毛病，挑对的只有 1 处。

于是你动了一个念头：把活分开。一个专管写，另一个专管查。

人就是这么干的。写代码的有人审，出报告的有人复核，会计和出纳从来不是同一位。

先用最省事的办法试一试。写的那一位，还是上一章的资料助手，工具和卡片一样不少。再请一位搭档，给它三句话的岗位说明：你是审查员，帮同事把事情办对，觉得可以交了就说“完成”。然后让它们自己聊。

办的事，是第 09 章那道把 Agent 难住的题：新同事 9 点提交账号申请，最早几点能做完环境自检？那一回它答 9:55，漏了“装开发工具”那一步。

```python
# chat.py：最省事的分工。一个写，一个查，让它们自己聊，聊到查的那一位说“完成”为止
import os
from llm import chat, SPENT
from assistant import build
from jobs import PLAN, ROOM, yes, done

CHECKER = """你是审查员，和你搭档的是一位负责动手的同事。它会把自己办的事告诉你。
你的职责是把关：帮它把这件事办对。看出问题就指出来，让它去改。
你认为可以交了，就在回复里写上【完成】。"""

def brief(text, n=150):
    text = " ".join(text.split())
    return text if len(text) <= n else text[:n] + "……"

if __name__ == "__main__":
    if os.path.exists("workspace/plan.md"):
        os.remove("workspace/plan.md")
    ask, plugs = build(confirm=yes)
    writer, checker = [], [{"role": "system", "content": CHECKER}]
    said = "用户交来一件事：" + PLAN
    for n in range(1, 7):                                        # 最多聊六个来回
        reply = ask(said, talk=writer, **ROOM)
        print(f"写的：{brief(reply)}\n")
        checker.append({"role": "user", "content": reply})
        said = chat(checker)
        checker.append({"role": "assistant", "content": said})
        print(f"查的：{brief(said)}\n")
        if "【完成】" in said:
            break
    for plug in plugs:
        plug.close()
    print(f"聊了 {n} 个来回，问了模型 {SPENT['calls']} 次，花了 {SPENT['tokens']} 个 token")
    print("plan.md 里的答案对不对：", "对" if done("plan.md", ["10:30|10:10"]) else "不对")
    print("\n" + open("workspace/plan.md", encoding="utf-8").read())
```

一个来回就完事了。写的这一回没漏步骤，答的是 10:30，对的。查的看完，回了两个字。

很顺。可是请想一想，查的那一位到底查了什么。

它手里没有资料库，也没有任何工具。写的说“依据 D03”，它没法打开 D03。它能看到的，只有写的那一位自己讲的那段话。那段话读着头头是道。

这一回写的碰巧是对的。要是写的错了呢？

第 09 章那份 9:55 的错答案，原文我们还留着。把它原样交给这位搭档。再多请两位来比一比：一位岗位说明写得很严，可同样没有工具；另一位说明一样严，还带着自己的工具，可以按编号取资料原文、重新查流程、重新算。每一位查三遍。

多了一个角色，账面上多了一道关。这道关到底把住了什么？

这个问题比语言模型老得多。

## 1980 年，两条老路

把时钟拨回 1980 年。那时候没有语言模型，可已经有人在认真琢磨：一件事一台机器办不了，要一群机器合起来办，它们之间该怎么配合？

先请你想一个很具体的情形。你手上有一件活要派出去。帮手有一群，可你不完全清楚谁会什么，也不知道谁这会儿有空。你怎么派？

合上书想半分钟。

1980 年 12 月，加拿大国防研究机构的里德·史密斯（Reid G. Smith）在一份计算机期刊上发表了一篇论文，写的是他在斯坦福读博士时做的东西。他的主意，就是你在生活里见过的那一种：**招标**。

有活的那个节点，向大家发一份任务通告。觉得自己能接的节点，回一份标书。发包的看过标书，把活判给它认为最合适的那一个。干活的干完了，把结果报回来。发包的还可以中途叫停一件活。

这套约定叫**合同网协议**（Contract Net Protocol）。论文里特别说明，谁发包、谁干活不是事先定死的：接了活的节点可以把活再拆开，往下分包，这时候它自己就成了发包的。

![[零基础学AI/attachments/第 12 章｜多请几个助手，事情就会更顺吗？/Y3OrbVz8co3r1UxZbGUc0fxanCd.png|1980 年前后的两条老路：招标，和黑板。]]

论文举的例子是一片传感器网络。有的节点算力强，可是没有传感器；有的节点带着传感器，算力很弱。算力强的要找带传感器的替它采信号。它发出去的那份通告有四个栏位：

任务摘要：采信号，我在北纬 47 度、东经 17 度。

资格说明：必须带传感器，必须在 A 区。

标书要求：报上你的位置，还有每个传感器的名字和型号。

截止时间：1979 年 2 月 28 日 17 点 30 分。

请记住这四栏。四十五年以后它们会再出现一次。

![[零基础学AI/attachments/第 12 章｜多请几个助手，事情就会更顺吗？/RN2ubCUEko28nUxO75CcTxjmnAe.png|1980 年的一份任务通告：谁带着天线，谁就举牌。]]

另一条路出自卡内基梅隆大学。1971 到 1976 年，那里有一组人在美国国防部高级研究计划局的资助下，做一个听懂人说话的系统，叫 Hearsay-II。

听懂一句话，要好几样本事：分辨声音，拼出音节，认出词，看这些词合不合语法，再看整句话说不说得通。这几样本事谁也离不开谁。听不清的那个音，常常要等“这句话大概在说什么”有了眉目，才猜得出来。

他们没有让这几样本事互相发消息。他们在中间放了一块**黑板**。

每样本事是一位“专家”，论文里叫知识源，1976 年的版本里有十来个。所有的半成品，这段声音可能是哪个音节，这几个音节可能是哪个词，都写在黑板上。每位专家只盯着黑板看，看到自己接得上的东西，就上去添一笔。专家之间不说话。旁边另有一个调度的，决定下一步轮到谁写。

![[零基础学AI/attachments/第 12 章｜多请几个助手，事情就会更顺吗？/VCR1bEwS6oRHzWxCRopcfCzgnCb.png|几位专家，一块黑板。谁接得上，谁上去添一笔。]]

两条路，各有一个从一开始就带着的难处。

招标这条路，难在**那张单子**。通告写得含糊，来投标的就五花八门；活判出去了，得一直有个节点对它负责；发包的还得能把它叫停。

黑板这条路，难在**那块板子**。谁都能往上写，那么两位同时写在一处怎么办？后写的把先写的盖掉了，又怎么办？

这两个难处，四十多年以后一个都没有少。

## 2023 年，它们换了一身衣服回来

2022 年底以后，人人手里都有了一个会说话的模型。很快有人想到：让两个模型对着说，会怎么样？

2023 年 3 月底，沙特阿卜杜拉国王科技大学的几位研究者发表了 CAMEL。两个模型各扮一个角色，一个出主意、下指令，一个动手干，一来一往地聊着把一件事办完。论文里的例子是让一位“股票交易员”和一位“Python 程序员”合作写一个交易机器人。

他们很诚实地记下了聊崩的样子：两位聊着聊着互换了角色；干活的把指令原样念一遍，就算回答；答应得很痛快，然后什么都没做；到最后来来回回说着没有内容的话，谁也停不下来。他们在提示词里不得不写上这样的话：

> Never flip roles! Never instruct me!

（绝不许互换角色！绝不许反过来指挥我！）

刚才那位只回两个字的搭档，你现在知道它是哪一路的了。

同年 7 月，清华大学的一组人把场面铺大，发表了 ChatDev。它是一家虚拟的软件公司，有首席执行官、首席技术官、程序员、审查员、测试员，照着瀑布式的开发流程，一个阶段一个阶段地两两对谈，把一个小软件做出来。

8 月，MetaGPT 出来了。它也是一家虚拟公司，可是主意正好反过来。作者们认为，模型之间的闲聊正是幻觉层层放大的地方。他们让每个角色照着标准作业流程干活，角色之间传的是**文档和图表**：产品经理交需求文档，架构师交设计文档，一道一道往下传，像一条流水线。

![[零基础学AI/attachments/第 12 章｜多请几个助手，事情就会更顺吗？/GJOnbCDBYogpDgx9GItchuadnig.png|一条流水线：往下传的是越来越厚的文件夹，聊天被划掉了。]]

两种路数摆在你面前了。请你押一注：**让几个助手互相聊天，还是让它们互相交东西？**

你大概已经有倾向了。可“交东西”三个字说着容易。交什么样的东西？收的那一位凭什么判断它行不行？

## 九份交上来的东西

来量一量。

我备了九份交上来的东西，都是几行字的小文件，每一条规定后面带着依据。三份是对的。另外六份里，各埋了一处毛病（全文附在章末的 `cases.py` 里）：

拿一份已经废止的旧规定当依据。

张冠李戴：把正式员工的 45 分钟写给了实习生。

无中生有：原文里没有“门禁卡”，它写了，还标着依据。

漏了一步：就是那份 9:55。

算错了：9:45 加 35 分钟，写成了 10:10。

有一句话没写依据，资料里也确实没有。

查的还是刚才那三位，再添一位：带着同样的工具，换一个模型（同一平台上的 `deepseek-v4.1-flash`）。

带工具的那一位是这样写的。它的工具全是只读的，它只能说行或者不行，不能动手改。

```python
def verdict(reply):
    """从它的回答里把那个 JSON 抠出来。抠不出来，按“没通过、说不清”算"""
    found = re.search(r"\{.*\}", reply or "", re.S)
    try:
        data = json.loads(found.group(0))
        return bool(data.get("pass")), [str(p) for p in data.get("problems", [])]
    except (AttributeError, ValueError):
        return False, ["审查员没有给出能读懂的结论：" + (reply or "")[:60]]

def read_only(material):
    """只读一遍"""
    return verdict(chat([{"role": "system", "content": READ}, {"role": "user", "content": material}], json_mode=True))

def check(material, quiet=True, hard_only=False):
    """带着工具查一遍。它的工具全是只读的：取原文、读文件、查资料、算数
    hard_only：只拦硬伤，别的只当建议"""

        else:
            reply = agent(material, tools, run, duty, most=12, budget=40000)
    finally:
        for plug in plugs:
            plug.close()
    return verdict(reply)

def check_hard(material):
    return check(material, hard_only=True)

def as_model(name):
    """这一段里换一个模型"""

        yield
    finally:
```

```python
import contextlib, io, os, shutil
from assistant import build
from reviewer import check, check_hard
from jobs import ROOM

REWORK = "审查没有通过，意见如下。请逐条处理：对的就改，改完重新存一遍；你认为意见不对，就说明理由，不要为了过审乱改。\n"

def files(folder="draft"):
    return sorted(f for f in os.listdir(folder) if not f.startswith(".")) if os.path.isdir(folder) else []

def package(goal, reply):
    """交给审查员的一包：用户要办的事，写的那位的汇报，它存下的文件"""
    text = f"用户要办的事：{goal}\n\n对方的汇报：\n{reply}\n"
    for name in files():
        text += f"\n对方交来的文件 {name}：\n" + open(os.path.join("draft", name), encoding="utf-8").read()
    return text + ("\n（文件都放在待审的文件夹里。文件名对就行，路径怎么写不算问题。）" if files() else "\n对方没有交文件。")

def desk(goal, review=check_hard, rounds=1, show=True):
    """返回 (发出去的文件, 审了几回, 最后一回的意见)。没过审，发出去的就是空的"""
    shutil.rmtree("draft", ignore_errors=True)
    os.environ["DESK_FOLDER"] = "draft"                      # 写的和查的，这一趟都只认 draft 这个文件夹
    try:
        ask, plugs = build(confirm=lambda: True)
        talk, say = [], goal
        for n in range(rounds + 1):
            with contextlib.redirect_stdout(io.StringIO()):
                reply = ask(say, talk=talk, **ROOM)
            passed, problems = review(package(goal, reply))
            if show:
                print(f"   第 {n + 1} 回送审：{'通过' if passed else '退回'}" + "".join("\n      " + " ".join(p.split())[:110] for p in problems))
            if passed:
                break
            say = REWORK + "\n".join("- " + p for p in problems)
        for plug in plugs:
            plug.close()
    finally:
        os.environ.pop("DESK_FOLDER")
    sent = files() if passed else []
    os.makedirs("workspace", exist_ok=True)
    for name in sent:                                        # 过了审，才搬进 workspace
        shutil.move(os.path.join("draft", name), os.path.join("workspace", name))
    return sent, n + 1, problems

def overrule(name, why):
    """仲裁。写的和查的僵住了，由你来定：你说放，就放，并且记一笔是谁放的、为什么"""
    shutil.move(os.path.join("draft", name), os.path.join("workspace", name))
    with open("workspace/.overruled.log", "a", encoding="utf-8") as log:
        log.write(f"{name}｜人工放行｜{why}\n")
    print(f"{name} 已由人工放行，搬进 workspace。理由记在案：{why}")

    print("plan.md 的答案：", "对" if done("plan.md", ["10:30|10:10"], "workspace" if sent else "draft") else "不对")
```

```python
import contextlib, io, os, sys
from llm import SPENT
from assistant import build

def solo(goal, again=False):
    ask, plugs = build(confirm=lambda: True)
    talk = []

    if again:
        ask(SELF, talk=talk, **ROOM)

        plug.close()

                if os.path.exists(os.path.join(folder, name)):
                    os.remove(os.path.join(folder, name))
            before = dict(SPENT)
            with contextlib.redirect_stdout(io.StringIO()):
                way(goal)
            ok = done(name, must)
            right, calls, tokens = right + ok, calls + SPENT["calls"] - before["calls"], tokens + SPENT["tokens"] - before["tokens"]
            print(f"{label}  {name:<11} {'办成' if ok else '没办成'}   问模型 {SPENT['calls'] - before['calls']:>2} 次  {SPENT['tokens'] - before['tokens']:>6} token")
            sys.stdout.flush()
        print(f"{label}  办成 {right} / {len(JOBS)}，一共问模型 {calls} 次，{tokens} token\n")
```

第 08 章我们学会了只认回执。这里回执是真的，事情却还是丢了。**一份回执只能证明“我写进去了”，证明不了“它还在”。**

黑板上两位专家同时写在一处，就是这个情形。Hearsay-II 靠那位调度的来排队。我们换一个更轻的办法：给文件记版本号。读的时候告诉你这是第几版；存的时候，你得说清自己是照第几版改的。对不上，就不让存。

```python
# files_server.py：带版本号的文件服务。读的时候告诉你这是第几版；存的时候要说清你是照第几版改的
import fcntl, json, os
from serve import serve, tool

ROOT, BOOK = "workspace", "workspace/.versions.json"

def inside(name):
    root = os.path.realpath(ROOT)
    path = os.path.realpath(os.path.join(root, name))
    return path if os.path.dirname(path) == root else None

def versions():
    return json.load(open(BOOK, encoding="utf-8")) if os.path.exists(BOOK) else {}

def read_file(name):
    path = inside(name)
    if not path or not os.path.isfile(path):
        return f"出错：workspace 里没有 {name}"
    return f"【{name} 第 {versions().get(name, 1)} 版】\n" + open(path, encoding="utf-8").read()

def save_file(name, content, based_on):
    path = inside(name)
    if not path:
        return f"拒绝：只能存进 workspace 文件夹，{name} 不在里面，什么都没写"
    os.makedirs(ROOT, exist_ok=True)
    with open(BOOK + ".lock", "w") as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)                    # 查版本和写文件，中间不许别人插进来
        book = versions()
        now = book.get(name, 1 if os.path.exists(path) else 0)
        if int(based_on) != now:
            return (f"拒绝：你是照第 {based_on} 版改的，可 {name} 现在已经是第 {now} 版了，有别人在你之后改过。"
                    "什么都没写。请重新读一遍最新的，在它上面改。")
        with open(path, "w", encoding="utf-8") as f:
            f.write(content)
        book[name] = now + 1
        json.dump(book, open(BOOK, "w", encoding="utf-8"))
    return f"已写入 workspace/{name}，现在是第 {now + 1} 版"

TOOLS = [tool("read_file", "打开 workspace 里的一个文件。返回的第一行会告诉你这是第几版。", read_only=True, name="文件名，如 day1.md"),
         tool("save_file", "把一份文件整份存回 workspace。必须说明你是照第几版改的；新建文件填 0。",
              name="文件名", content="文件的全部内容", based_on="你读到的版本号，是一个整数")]

if __name__ == "__main__":
    serve("带版本号的文件服务", TOOLS, {"read_file": read_file, "save_file": save_file})
```

## 拆，还是不拆

该回答这一章的题目了。多请几个助手，事情就会更顺吗？

我们自己的数说：不一定。九份有毛病的东西，查的那位立了功。六件本来就办得成的事，它帮了倒忙。

这两年，认真量过这件事的人不少。他们量出来的数，和我们的方向一致，只是摆幅大得多。

2025 年 3 月，加州大学伯克利分校的一组人把七个流行的开源多 Agent 框架拿来跑任务，一条一条看失败的记录，标注了一千六百多条。这些框架的失败率从 41% 到 86.7% 不等。他们把失败的原因归成三类十四种：系统设计上的，几个 Agent 之间没对齐的，任务验证上的。出现得多的几种，你读着会觉得眼熟：反复做已经做过的步骤；没意识到事情已经办完；任务一开始就没交代清楚。他们的结论是，这些失败常常出在系统怎么设计上，不能只怪模型不够强。

2025 年 6 月，隔着一天，有两篇文章先后登出来，标题读着像在吵架。

一篇是 Cognition 公司的，题目就叫《别造多 Agent》。里面举了个例子：让两个子 Agent 合做一个 Flappy Bird 小游戏，一个画背景，一个画小鸟。画背景的交回来一幅超级马里奥风格的画面，画小鸟的交回来一只完全不搭调的鸟。谁也没做错自己那一份，合在一起没法用。作者的意思是：每一个动作里都藏着没说出口的决定，分开干的两位，各自做了互相冲突的决定。

另一篇是 Anthropic 的，讲他们怎么造了一个多 Agent 的研究系统。一个领头的拆题、派活，几个子 Agent 同时去查，查完交回来。在他们内部的一套研究类考题上，这个系统比单个 Agent 好 90.2%。同一篇文章也交代了代价：多 Agent 系统用掉的 token 大约是普通聊天的 15 倍。他们还说，要所有 Agent 共用同一份上下文的任务、互相牵扯很多的任务，眼下并不适合这么干。

两篇文章其实没有吵起来。它们说的是两类不同的任务。查资料，可以分头去查，各查各的，互不相干。做一个游戏，画面和小鸟得长在一起。

2025 年 12 月，谷歌和麻省理工的一组研究者把这件事量得更细。他们在六类任务上试了 260 种配置。结果是两头的：能拆开的任务，多 Agent 最多好了 80.8%；一步靠着一步的规划任务，最多差了 70.0%。他们还量到两件事。几个 Agent 各干各的、没有统一把关的时候，错误会被放大 17.2 倍；有一个居中协调的，是 4.4 倍。单个 Agent 自己已经能做对四成五以上的任务，再添 Agent，得到的是负数。

最后这一条，就是我们那张成绩单。一个人六件全成，添人只有亏。

```python
# helper.py：一个帮手，单独一个进程。python3 helper.py 名字 开始时刻 用哪套文件工具 要办的事
import contextlib, io, json, sys, time
from host import connect, ROLE
from agent import agent
from jobs import ROOM

name, start, kind, goal = sys.argv[1], float(sys.argv[2]), sys.argv[3], sys.argv[4]
if kind == "老办法":          # 上一章的两样：读文件，整份存回去
    scripts, only = ["docs_server.py", "check_server.py"], {"search_docs", "calc", "save_file", "read_file"}
else:                        # 带版本号的那一套
    scripts, only = ["docs_server.py", "files_server.py"], {"search_docs", "calc", "read_file"}
tools, run, plugs = connect(scripts, confirm=lambda: True, only=None)
tools = [t for t in tools if t["function"]["name"] in only or (kind != "老办法" and t["function"]["name"] == "save_file")]
if kind != "老办法":          # 两个服务都有 save_file，只留带版本号的那个
    tools = [t for t in tools if not (t["function"]["name"] == "save_file" and "based_on" not in t["function"]["parameters"]["properties"])]

def watched(call):
    """照办之前之后各记一笔：谁，第几秒，对哪个文件做了什么"""
    result = run(call)
    what = call["function"]["name"]
    if what in ("read_file", "save_file"):
        sys.__stdout__.write(f"{time.time() - start:5.1f} 秒  {name}  {what:<9}  →  {' '.join(result.split())[:46]}\n")
        sys.__stdout__.flush()
    return result

with contextlib.redirect_stdout(io.StringIO()):
    reply = agent(goal, tools, watched, ROLE, **ROOM)
sys.__stdout__.write(f"{time.time() - start:5.1f} 秒  {name}  说：{' '.join(reply.split())[:60]}\n")
for plug in plugs:
    plug.close()
```

```python
import os
from serve import serve, tool
from docs import DOCS, show

def get_doc(id):
    for doc in DOCS:
        if doc["id"] == id.strip().upper():
            return show(doc)
    return f"出错：没有编号为 {id} 的资料"

FOLDER = os.environ.get("DESK_FOLDER", "workspace")

def read_file(name):
    root = os.path.realpath(FOLDER)
    path = os.path.realpath(os.path.join(root, name))
    if os.path.dirname(path) != root or not os.path.isfile(path):
        return f"出错：{FOLDER} 里没有 {name}"
    return open(path, encoding="utf-8").read()
```

```python
def done(name, must, folder="workspace"):
    path = os.path.join(folder, name)
    if must is None:
        return not os.path.exists(path)
    text = open(path, encoding="utf-8").read().replace("：", ":") if os.path.exists(path) else ""
    if name == "plan.md" and "10:30" not in text:          # 写 10:10 的，得真说了“同时”才算；漏掉下载那 20 分钟也会凑出 10:10
        return "10:10" in text and ("同时" in text or "并行" in text) and "20" in text
    return all(any(w in text for w in word.split("|")) for word in must)
```
