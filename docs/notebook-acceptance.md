## 已确认的行为与限制

- 修改代码或依赖文件后，旧输出会标记失效；新执行结果才用于当前预测对照。
- 停止或重置会清空运行变量，保留代码和历史记录。重新打开不会假装旧内核仍在，恢复执行由读者主动触发。
- 表格输出采用结构化文本，不渲染读者输出的 HTML。过大的表格或历史文字有截断提示。
- 大图保留在当前会话；本机历史不持久保存大图，界面明确提示重新执行或下载当前 Notebook。
- Linux / GPU 网关尚未接通，对应远端实验不计为完成；测试中的模拟网关响应不能替代实际服务验收。
- 生产环境账号同步本次未重新登录验证。以上浏览器结果来自开发预览，不能替代生产账号隔离、跨设备同步或远端服务的实际验证。
