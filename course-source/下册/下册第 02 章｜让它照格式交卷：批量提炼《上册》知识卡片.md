## 上一章留下的定时炸弹

上一章的 `index_kb.py` 虽然跑出了《上册知识库目录.md》，但只要下游程序想干两件稍微正经点的事——比如“统计哪个主题的笔记最多”或者“按标签把笔记分组”——立刻就会发现它根本没法直接用：

自然语言是给人看的，程序要吃的是**结构化数据**。今天这一章，我们要把模型从“自由发挥写一段话”，驯服成“严格按 Schema 交卷”。

## 光写“请输出 JSON”为什么一定会翻车？

几乎所有初学者写的第一版提示词都长这样：“请只输出合法的 JSON，不要任何多余文字。”

真跑上二十几次，你会见识到模型花样百出的翻车方式：

1. **外面套一层 Markdown 代码围栏**：嘴上答应只输出 JSON，手却很诚实地给你包了一层 ```` ```json ... ``` ````，直接 `json.loads()` 当场 `JSONDecodeError`；
2. **字段名悄悄改写或漏掉**：你要 `core_question`，它有时给你 `summary`；你要 2–3 条 `takeaways`，它有时只给 1 条，或者干脆塞给你一段长字符串而不是数组；
3. **分类标签天马行空**：你让它归类，它这篇写 `机器学习`，下一篇写 `AI基础`，再下一篇写 `大模型原理`——25 篇文章能给你造出 18 个分类名，聚合统计彻底作废。

## 三道防线：接口约束 + 边界校验 + 带错因重试

要让外部模型稳定交出合规数据，必须在 `课件/ch02/llm.py` 里同时上三道防线：

### 第一道防线：接口层 `response_format` + 剥离代码围栏 `extract_json()`

调用 Chat Completions 时在请求体里加上 `response_format={"type": "json_object"}`，告诉服务端约束输出为合法 JSON；同时在本地写一个 `extract_json()` 兜底，万一某些兼容平台还是包了 ```` ```json ````，先用正则剥干净再 `json.loads()`。

### 第二道防线：代码层 Schema 校验 + 封闭词表（`validate_card`）

JSON 语法合法，不代表业务字段合法。我们专门定义一个 `SchemaError` 异常，在 `validate_card()` 里把四条死规矩写进 Python 代码：

- 必填 5 个字段（`title`、`topic`、`core_question`、`takeaways`、`terms`）一个不能少；
- **`topic` 必须落在封闭词表 `ALLOWED_TOPICS` 里**（`["导论与总览", "机器学习基础", "大语言模型", "检索与RAG", "Agent与工具", "记忆与协作", "工程交付"]`），不许模型自己发明第 8 个分类；
- `takeaways` 必须是包含 2–3 条字符串的数组，`terms` 必须是包含 1–5 个术语的数组；
- 每个字符串字段都必须非空。

### 第三道防线：把具体错因递回去纠错（`ask_json`）

以前校验失败，很多人第一反应是 `for _ in range(3): chat(...)` 重试三遍。但在 `temperature=0` 且开启缓存的情况下，原封不动重问一百遍，回来的还是同一份错卷。

正确的做法是**把模型刚才交上来的错卷和具体的 `SchemaError` 报错信息一起塞回对话里**，让它像订正错题一样只改错的那一处，最多重试 1 次：

![[零基础学AI/attachments/下册第 2 章｜让它按格式回答：一张卡片，一张词表/QE5kb6fFUo77xyxKN4Yc79LDnod.png|校验失败时把错因递回去，而不是盲目重跑。]]

下面是 `课件/ch02/llm.py` 在第 01 章基础上新增的核心代码：

```python
# llm.py（第 02 章新增部分）
class SchemaError(LLMError):
    """模型回来的 JSON 虽然语法对，但缺字段、类型不对或超出约定词表。"""


def extract_json(text):
    """从可能包了 ```json ... ``` 的回复里剥出 JSON 对象。"""
    s = text.strip()
    if s.startswith("```"):
        s = re.sub(r"^```[a-zA-Z]*\n?", "", s)
        s = re.sub(r"\n?```$", "", s.strip())
    return json.loads(s)


def ask_json(messages, validator, model=None, use_cache=None):
    """要求模型交出严格合规的 JSON；若校验失败，把具体错因递回去最多重试 1 次。"""
    if isinstance(messages, str):
        messages = [{"role": "user", "content": messages}]
    msgs = list(messages)
    last_err = None
    for attempt in range(2):
        raw = chat(
            msgs,
            model=model,
            temperature=0,
            use_cache=use_cache,
            response_format={"type": "json_object"},
        )
        try:
            obj = extract_json(raw)
            return validator(obj)
        except (ValueError, SchemaError) as e:
            last_err = e
            if attempt == 0:
                msgs = msgs + [
                    {"role": "assistant", "content": raw},
                    {
                        "role": "user",
                        "content": f"格式校验未通过：{e}。请只输出修正后的合法 JSON，不要任何解释。",
                    },
                ]
    raise SchemaError(f"连续两次未通过格式校验：{last_err}")
```

> **老办法，新地方**
>
> “外部输入进门前先过严格 Schema 校验，不合法就拒绝入库并给出明确错误原因”，这在传统后端开发里叫**边界校验（Boundary Validation）**。无论模型多聪明，在你的 Python 程序眼里，它发回来的字符串和网页表单提交的数据一样属于**不可信输入**——永远不要把未经 `validator()` 检查的内容直接写入知识库。

## 本章实战成品：批量提炼《上册》知识卡片

现在把整套机制跑在 `零基础学AI/上册/` 全部 25 篇笔记上。完整代码见 `课件/ch02/cards.py`：

```python
# cards.py：第 02 章实战成品——批量把《上册》笔记提炼成严格 Schema 的结构化知识卡片（JSONL + 词表对齐）
import json
import os
import sys
import llm

DEFAULT_KB = os.path.abspath(os.path.join(os.path.dirname(__file__), "../../../上册"))
ALLOWED_TOPICS = ["导论与总览", "机器学习基础", "大语言模型", "检索与RAG", "Agent与工具", "记忆与协作", "工程交付"]

PROMPT = f"""请阅读下面这篇《从零开始学 AI》笔记节选，严格输出一个 JSON 对象，包含且仅包含以下 5 个字段：
- "title": 字符串，章节标题
- "topic": 字符串，必须从这个词表里选一个：{json.dumps(ALLOWED_TOPICS, ensure_ascii=False)}
- "core_question": 字符串，这一章解决的核心问题（不超过 30 字）
- "takeaways": 字符串数组，2 到 3 条核心结论，每条不超过 35 字
- "terms": 字符串数组，2 到 4 个关键术语

笔记内容：
"""


def validate_card(obj):
    if not isinstance(obj, dict):
        raise llm.SchemaError("顶层必须是 JSON 对象")
    required = ("title", "topic", "core_question", "takeaways", "terms")
    for k in required:
        if k not in obj:
            raise llm.SchemaError(f"缺少必填字段：{k}")
    if obj["topic"] not in ALLOWED_TOPICS:
        raise llm.SchemaError(f"topic={obj['topic']!r} 不在允许词表 {ALLOWED_TOPICS} 中")
    if not isinstance(obj["takeaways"], list) or not (2 <= len(obj["takeaways"]) <= 3):
        raise llm.SchemaError("takeaways 必须是包含 2–3 条字符串的数组")
    if not isinstance(obj["terms"], list) or not (1 <= len(obj["terms"]) <= 5):
        raise llm.SchemaError("terms 必须是包含 1–5 个术语的数组")
    return obj


def clean_preview(raw_text, limit=1800):
    lines = raw_text.splitlines()
    if lines and lines[0].strip() == "---":
        for i in range(1, len(lines)):
            if lines[i].strip() == "---":
                lines = lines[i + 1 :]
                break
    kept = [ln for ln in lines if not ln.strip().startswith(("![[", "> 🎬"))]
    return "\n".join(kept).strip()[:limit]


def main():
    folder = os.path.abspath(sys.argv[1]) if len(sys.argv) > 1 else DEFAULT_KB
    out_path = os.path.join(os.path.dirname(__file__), "cards.jsonl")
    md_files = sorted(f for f in os.listdir(folder) if f.endswith(".md") and f != "上册知识库目录.md")

    cards, failed = [], []
    for name in md_files:
        preview = clean_preview(open(os.path.join(folder, name), encoding="utf-8").read())
        try:
            card = llm.ask_json(PROMPT + preview, validator=validate_card)
            card["file"] = name
            cards.append(card)
        except llm.LLMError as e:
            failed.append((name, str(e)))

    with open(out_path, "w", encoding="utf-8") as f:
        for c in cards:
            f.write(json.dumps(c, ensure_ascii=False) + "\n")

    print(f"生成完成：{len(cards)} 张卡片写入 {out_path}，失败 {len(failed)} 篇")
    for name, err in failed:
        print(f"  失败 {name}：{err}")
    print(llm.bill(price_in=1.0, price_out=4.0))


if __name__ == "__main__":
    main()
```
