# 《从零开始学 AI》讲解视频制作经验沉淀与复用指南

这份指南总结了第 01–03 章共 6 集讲解视频（`Ep 1.1` – `Ep 3.2`）的完整实战经验、技术管线与避坑清单，供后续章节或同类知识视频直接复用。

---

## 一、核心叙事原则（决定视频好不好看）

1. **严格忠于原书故事线，绝不在 `0:00` 剧透**
   - 必须保留“回到当年现场 → 给你当年的人手里的筹码 → 让你先押一注 → 再揭晓结果与背后原理”的递进感。
   - 反面教训：不要一上来就把结论拍在脸上（例如不要在开头直接说“规则会打架、感知机做不到异或”），而是先让观众看到 6 行代码的成功或第 37 手的骚动，产生好奇后再往下走。
2. **按“核心问题 + 反转”拆集，每集控制在 2–3 分钟（130–170 秒）**
   - 一章拆成 2 集左右，每集围绕一个闭环展开（例如 Ep 2.1 讲“1958 感知机与楼梯灯困境”，Ep 2.2 讲“1986 反向传播、2012 转折点与 v0.2”）。
   - 每集拆成 5–6 个镜头（Shots），每句旁白控制在 15–30 字，每 2–3 秒安排一次视觉元素弹出或状态切换。
3. **设计“3·2·1”互动押注停顿**
   - 在程序运行结果或关键历史抉择前（如“考卷 6 句能对几句？”、“能不能只画一条直线分开？”），在语音后留 `2.2s` 停顿，配合右侧圆环 `3·2·1` 倒计时动画，让观众真正参与猜测。

## 二、视觉与排版规范（暖米白纸面手绘风）

| 项目 | 规范参数 |
|-|-|
| 分辨率与帧率 | `1920 × 1080`，`30 fps`，`libx264`（`-preset medium -crf 19 -pix_fmt yuv420p`） |
| 背景底色与网格 | 纸面米白 `#F7F4EC (247,244,236)` + 60px 浅格线 `#EAE5D6 (234,229,214)` |
| 主题色板 | 藏青 `#1E3A5F`（标题/常规卡片）、青绿 `#2A7B76`（成功/核心结论）、赭黄 `#C88A36`（提问/提醒）、砖红 `#C0564B`（报错/反例）、终端底 `#1E2733` |
| 画面稳定性 | 保持平视稳态镜头，不加全局晃动或颗粒噪点滤镜；四角保留固定手绘小叶片/圆点装饰 |
| 顶部 HUD | 左上角胶囊显示当前集标题；右上角胶囊显示进度条（`当前镜头 / 总镜头数`） |
| 底部字幕 | 居中深灰半透明圆角胶囊 `(44, 52, 64, 228)`，白字 `38pt` 粗体；单行宽度超过 `1480px` 时从中间拆成两行 |
| 原书插图复用 | 直接读取 `零基础学AI/attachments/第 XX 章.../` 下的 PNG，用圆角遮罩 + 投影贴入；需要聚焦时仅做极轻缓推（`scale 1.0 → 1.03`） |

## 三、音频管线与响度标准

1. **配音合成（`audio_build.py`）**
   - 使用 `edge-tts`（`zh-CN-YunxiNeural`，`rate=+10%`，需联网）。
   - 每句单独合成为 `.mp3` 并转为 `48kHz` 单声道 `PCM WAV`，精确读取每段时长，写入 `timeline.json`（包含 `shot`、`start`、`end`、`pause_after`、`text`）。
   - 渲染脚本严格读取 `timeline.json` 的时间戳触发动画和字幕，保证**音画毫秒级对齐**。
2. **背景配乐与自动闪避（Ducking）**
   - 用 `numpy` 合成柔和的 C–G–Am–F 四和弦垫音，音量基底 `0.08`。
   - 根据人声包络平滑卷积后自动压低伴奏（ducking 系数 `0.35–1.0`），片尾做 `1.2s` 淡出。
3. **响度标准化**
   - 通过 `ffmpeg` 统一标准化到播客/教程黄金响度：`-af "loudnorm=I=-15:TP=-1.5:LRA=11,aformat=channel_layouts=stereo"`，输出 `48kHz` 立体声 `AAC 192k`。

## 四、踩过的坑与硬性避坑清单

1. **代码块字体缺字（渲染成 `□□`）**
   - `Menlo.ttc` 等西文等宽字体不包含中文，一旦代码注释或输出里出现中文就会变方块。
   - **解法**：所有文字与代码块统一使用 `/System/Library/Fonts/STHeiti Medium.ttc`（正文可用 `STHeiti Light.ttc`）。
2. **对勾/叉号字符缺字（渲染成 `▯`）**
   - `STHeiti` 不包含 `✓`、`✗` Unicode 字符。
   - **解法**：绝不直接打印 `✓`/`✗`，统一用 Pillow 矢量画线函数 `draw_mark(dr, x, y, ok=True/False)` 绘制青绿对勾与砖红叉号。
3. **坐标轴标签压线**
   - 绘制 2×2 象限图或坐标图时，原点 `(0,0)` 或横轴上的点标签不要直接放在 `py - 14`，容易被横轴线穿过，应适当向轴外偏移。
4. **外部视频生成 API 的权限边界**
   - 现阶段本地 Pillow + `ffmpeg` + `edge-tts` 管线完全可控、零外部依赖失败风险、风格与原书手绘插图 100% 统一，是最稳妥的主力方案。

## 五、标准执行流与验收清单

1. **本地运行环境**：`~/.video-venv`（已预装 `pillow 11.3.0`、`numpy 2.0.2`、`imageio-ffmpeg 0.6.0`、`edge-tts 7.3.1`）。
2. **两步生成**：
   - 第 1 步（需联网）：运行 `audio_build.py` 生成 `mix_final.wav` 与 `timeline.json`。
   - 第 2 步（纯离线）：运行 `render_epX_Y.py` 将 RGB 帧流式管道传给 `ffmpeg` 合成 `.mp4` 到 `零基础学AI/上册/videos/`。
3. **抽帧视觉验收**：每次渲染完成后，用 `ffmpeg` 抽取 4 个关键时间点（含代码页、倒计时页、插图页、总结页）的 PNG 并肉眼检查，确认无文字溢出、无遮挡、无方块字。
4. **嵌入 Obsidian 正文**：在对应小节末尾使用库内绝对路径嵌入：
   ```markdown
   > 🎬 **配套视频｜Ep X.Y：本集标题**
   ![[零基础学AI/上册/videos/0X-Y_文件名_v1.mp4]]
   ```
5. **目录改名注意**：尽量直接写入目标目录；若对文件夹做过整体删除重建或改名，记得用 `mkdir + cp` 重建文件节点或在 Obsidian 中按 `Cmd + R` 刷新索引。
